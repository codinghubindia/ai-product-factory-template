# Distribution Workspace

Stores creator vetting analyses, shortlists, outreach pitches, and collaboration campaign structures per product.

---

## Directory Conventions

```
distribution/<product_id>/
├── creator-shortlist.md     # Ranked creator candidates evaluated against 7-dimension vetting criteria
└── outreach/                # Tailored collaboration packs per creator
    └── <creator_slug>.md    # Personalized pitch, demonstration concepts, hooks, and proposed commercial terms
```

*Distribution Rule:* Vetting must prioritize audience pain alignment and demonstration viability over vanity follower counts. Fabricated metrics or fake engagement rates are strictly prohibited.
