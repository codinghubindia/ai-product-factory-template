# Packaging Workspace

Stores commercial presentation assets, sales copy, offer architecture, and mockup assets per product.

---

## Directory Conventions

```
packaging/<product_id>/
├── packaging-spec.md        # Product title, positioning statement, offer tiering, and bonus stack
├── copy/
│   ├── description.md       # Product description, problem-solution narrative, and benefits breakdown
│   ├── landing-page.md      # Full landing page copy (hero, features, FAQ, objection handling, CTA)
│   └── social-hooks.md      # Short-form hooks and talking points for promotions
└── mockups/                 # 2D/3D mockup asset directions and hero visuals
```

*Packaging Rule:* All claims, benefits, and bonus items must map directly to completed, audited components in `products/<product_id>/final/`.
