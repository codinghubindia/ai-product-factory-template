# Research Workspace

This directory stores all evidence, domain context, problem clusters, competitive intelligence, and opportunity records.

---

## Directory Organization

- **`raw/`**
  - Unfiltered scrape dumps, community thread notes, customer review transcripts, and raw notes captured by the `scout` agent.
- **`verified/`**
  - Fact-checked claims, audited source reports (`source-audit.md`), and domain benchmark reports produced by `source-auditor` and `research` agents.
- **`synthesis/`**
  - Structured problem clusters (`pain-clusters.md`) generated by `pain-miner`.
  - Competitive landscape and gap analysis (`competitive-analysis.md`) generated by `competitor`.
  - **`synthesis/opportunities/`**
    - Granular markdown dossiers for scored opportunities (`<opportunity_id>.md`) generated by `opportunity-analyst`.
