# Design Workspace

Stores visual systems, component rules, palette definitions, and formatting standards per product.

---

## Directory Conventions

```
design/<product_id>/
├── design-system.md         # Comprehensive visual specification (palette, typography, layout, components)
└── assets/                  # Brand assets, mood boards, or generated visual elements
```

*Design Rule:* All visual formatting must adhere strictly to the Six Pillars of Premium Design (Coherence, Clarity, Usability, Consistency, Intentionality, Polish).
